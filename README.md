## 🌟 Key Features & Interactive Showcases

- **🌌 Dynamic Particle Constellation Network**: High-performance HTML5 canvas animation simulating microservice data packets flowing through distributed clusters, responding interactively to mouse cursor motion.
- **⚡ Spring Boot Code Terminal (Hero Section)**: Live tabbed code viewer with syntax highlighting and 1-click copy showcasing:
  - `HospitalController.java` (Spring Boot REST Controller with JWT validation & `@PreAuthorize`)
  - `DoctorFeignClient.java` (OpenFeign declarative RPC client)
  - `JwtSecurityConfig.java` (Spring Security 6 stateless filter chain)
- **🧩 Interactive Microservices Architecture Explorer**: Visual clickable node graph of the distributed **Hospital Management System** (Spring Cloud Gateway, Netflix Eureka Registry, Auth, Patient, Doctor, Appointment, and Billing Services with isolated MySQL databases).
- **🧪 Live REST API Tester Sandbox**: Recruiter-friendly interactive testing console executing mock requests against Spring Boot endpoints (`POST /api/v1/auth/login`, `GET /eureka/apps`, `POST /api/v1/payments/razorpay/verify`, `GET /api/v1/appointments/available-slots`) with status `200 OK`, latency indicators, and formatted JSON.
- **🚀 Featured Projects Grid**: Filterable by `Microservices` and `Full-Stack` with modal architecture deep-dives:
  - **Hospital Management System** (Microservices Architecture, Eureka, OpenFeign, Cloud Gateway, JWT)
  - **TechStore** (E-Commerce Platform, Docker, Razorpay Gateway, OAuth 2.0, ~30% load speedup)
  - **MyTeachingApp** (LMS, RBAC, Razorpay, ~25% lower latency)
- **📊 Categorized Skills Matrix**: Interactive tabs for Backend & Microservices, Core Languages, Frontend, DevOps & Tooling, and Core CS (OOP, DSA, System Design).
- **🎓 Verified Certifications**: 1-click verified credential links from **Oracle**, **Meta**, **IBM**, and **AICTE**.
- **📬 Contact & 1-Click Copy**: Instant clipboard copy with toast notifications and confetti effect for Email and Phone.
- **📄 Printable Resume / CV**: Built-in modal with clean printable curriculum vitae layout (`window.print()`).

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 1. Clone the Repository
```bash
git clone https://github.com/Faiz-Khan01/faiz-khan-portfolio.git
cd faiz-khan-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000/`.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.
